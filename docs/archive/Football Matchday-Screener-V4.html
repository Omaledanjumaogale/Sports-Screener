Screening tool only — ranks and flags options based on the odds and league context you provide, using thresholds calibrated from general football knowledge and a small number of real sample matches rather than a backtested dataset. It does not raise win probability beyond what the market already prices in. Nothing here guarantees "beating the bookmaker" — it only helps you prioritize which matches are worth a closer look and which aren't. The Screening Log lives only in this browser tab's memory unless exported; this file uses no browser storage APIs and makes no network calls, to preserve full offline operation. Not financial advice.
